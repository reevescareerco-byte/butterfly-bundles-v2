Step-by-Step Instructions

Exactly How to Play

You will process one authorization case at a time. Complete these four steps for every case.

1
Read every case detail.

Review the requested service, member eligibility, diagnosis, provider order, clinical notes, payer requirements, and deadline. Do not choose an action until you have read the full case.

2
Select all findings that matter.

Click every checklist item that is true and affects the authorization. You may need to select more than one item. Selected items will turn purple.

3
Choose one final action.

Select Submit when the request is complete, Follow Up when information is missing or must be corrected, or Escalate when the case is urgent, overdue, or outside standard authority.

4
Read the coaching before advancing.

After you choose an action, the game shows the correct findings, correct decision, and reason. Then select Next Case to continue.

Example: If eligibility is active, the order is signed, and all required clinical notes are attached, select those findings and choose Submit. If the provider order is missing, select that finding and choose Follow Up.
